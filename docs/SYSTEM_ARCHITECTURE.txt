4. NLP PIPELINE (14 Stages in Detail)
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│                        14-STAGE DIALOGUE PIPELINE                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Input: User Query, Session ID, User Context                           │
│                                                                         │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │ Stage 1: INITIALIZATION                                           │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │ • Load session state from store                                   │ │
│  │ • Create trace context (correlation_id)                           │ │
│  │ • Execute BEFORE_DIALOGUE hooks                                   │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │ Stage 2: EVENT PUBLISHING                                         │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │ • Publish TURN_STARTED event                                      │ │
│  │ • Notify event subscribers                                        │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │ Stage 3: QUERY PREPROCESSING                                      │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │ • Execute BEFORE_PREPROCESSING hooks                              │ │
│  │ • Apply query summarization (if enabled)                          │ │
│  │ • Execute AFTER_PREPROCESSING hooks                               │ │
│  │                                                                   │ │
│  │   Example: "আমার জাতীয় পরিচয়পত্রের স্ট্যাটাস..."            │ │
│  │            ↓                                                      │ │
│  │            "NID স্ট্যাটাস চেক"                                  │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │ Stage 4: CONTEXT AUGMENTATION                                     │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │ • Check if fractional query (using classifier)                    │ │
│  │ • If yes, augment with last_context_tag from session              │ │
│  │                                                                   │ │
│  │   Example: User: "কত টাকা লাগবে?"                                │ │
│  │            Last context: "address_change"                         │ │
│  │            ↓                                                      │ │
│  │            Augmented: "ঠিকানা পরিবর্তন করতে কত টাকা লাগবে?"    │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │ Stage 5: NER EXTRACTION                                           │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │ • Extract named entities using regex patterns                     │ │
│  │ • Entities: NID numbers, phone, dates, names, amounts             │ │
│  │                                                                   │ │
│  │   Example: "আমার NID 1234567890123 এর স্ট্যাটাস"               │ │
│  │            ↓                                                      │ │
│  │            Entities: { "nid_number": "1234567890123" }            │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │ Stage 6: NLP PROCESSING (CLASSIFICATION + SEARCH)                 │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │ • Execute BEFORE_NLP hooks                                        │ │
│  │                                                                   │ │
│  │ ┌─────────────────────────────────────────────────────────────┐  │ │
│  │ │  A. CLASSIFICATION (48 intents)                             │  │ │
│  │ │  ───────────────────────────────────                        │  │ │
│  │ │                                                             │  │ │
│  │ │  Input: "আমার NID এর স্ট্যাটাস কি?"                       │  │ │

┌─────────────────────────────────────────────────────────────────────────┐
│                    POLICY ENGINE (Chain of Responsibility)              │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Input: NLP Result, Session State, User Context                        │
│                                                                         │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  Policy 1: ESCALATION POLICY                                      │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │                                                                   │ │
│  │  Trigger Conditions:                                              │ │
│  │    • Session has error_count >= 3                                 │ │
│  │    • User explicitly requests agent ("মানুষের সাথে কথা")        │ │
│  │                                                                   │ │
│  │  Decision:                                                        │ │
│  │    IF triggered:                                                  │ │
│  │      → Action: ESCALATE_TO_HUMAN                                  │ │
│  │      → Cancel active form (if any)                                │ │
│  │      → Return escalation message                                  │ │
│  │    ELSE:                                                          │ │
│  │      → Pass to next policy                                        │ │
│  │                                                                   │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │  Policy 2: ACTIVE FORM POLICY                                     │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │                                                                   │ │
│  │  Check: Is there an active form in session?                       │ │
│  │                                                                   │ │
│  │  IF YES:                                                          │ │
│  │    ┌────────────────────────────────────────────────────────┐    │ │
│  │    │  Interruption Handler                                  │    │ │
│  │    ├────────────────────────────────────────────────────────┤    │ │
│  │    │                                                        │    │ │
│  │    │  Is query a FAQ question?                              │    │ │
│  │    │    (classification confidence > 0.7 AND               │    │ │
│  │    │     query doesn't match slot values)                  │    │ │
│  │    │                                                        │    │ │
│  │    │  IF YES:                                               │    │ │
│  │    │    interruption_count < max (3)?                       │    │ │
│  │    │      YES → Allow interruption                          │    │ │
│  │    │            • Process FAQ                               │    │ │
│  │    │            • Increment interruption_count              │    │ │
│  │    │            • Return FAQ + resume prompt                │    │ │
│  │    │      NO  → Deny interruption                           │    │ │
│  │    │            • Return "Please complete form first"       │    │ │
│  │    │                                                        │    │ │
│  │    │  IF NO (query is slot value):                          │    │ │
│  │    │    • Validate & fill slot                              │    │ │
│  │    │    • Check if form complete                            │    │ │
│  │    │      YES → Execute form, return result                 │    │ │
│  │    │      NO  → Request next slot                           │    │ │
│  │    │                                                        │    │ │
│  │    └────────────────────────────────────────────────────────┘    │ │
│  │                                                                   │ │
│  │  ELSE (no active form):                                           │ │
│  │    → Pass to next policy                                          │ │
│  │                                                                   │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │  Policy 3: FORM TRIGGER POLICY                                    │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │                                                                   │ │
│  │  Check: Does predicted intent trigger a form?                     │ │
│  │                                                                   │ │
│  │  Form Mappings (from config/dialogue.json):                       │ │
│  │    {                                                              │ │
│  │      "nidStatusCheck": "NIDStatusCheckForm",                      │ │
│  │      "nameCorrectionDocuments": "CorrectionRequestForm",          │ │
│  │      "onlineApplicationProcess": "ApplicationForm",               │ │
│  │      ...                                                          │ │
│  │    }                                                              │ │
│  │                                                                   │ │
│  │  Decision:                                                        │ │
│  │    IF intent in form_mappings AND confidence > threshold:         │ │
│  │      → Action: START_FORM                                         │ │
│  │      → Initialize form                                            │ │
│  │      → Save to session                                            │ │
│  │      → Request first slot                                         │ │
│  │    ELSE:                                                          │ │
│  │      → Pass to next policy                                        │ │
│  │                                                                   │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │
│  ┌───────────────────────────────▼───────────────────────────────────┐ │
│  │  Policy 4: FAQ POLICY                                             │ │
│  ├───────────────────────────────────────────────────────────────────┤ │
│  │                                                                   │ │
│  │  Check: Is confidence above threshold?                            │ │

│  │    ELSE:                                                          │ │
│  │      → Pass to next policy                                        │ │
│  │                                                                   │ │
│  └───────────────────────────────┬───────────────────────────────────┘ │
│                                  │                                     │

│  │                                                                   │ │
